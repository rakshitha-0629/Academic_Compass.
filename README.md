# Academic Compass
An AI-powered Student Operating System that automatically transforms academic emails and notifications into organized tasks, study resources, and competition trackers.

## 🌐 Live Working Prototype
https://lovable.dev/preview/Qg50PqRoEKyknMsfBnnrbA0oRerrzQiI

## 📌 Main Modules
1. *AI Inbox:* Converts unstructured emails/circulars into structured actionable data.
2. *Competition Hub:* Hackathons, workshop guides, and AI mentor tracking.
3. *Study Hub:* Lecture summaries, auto-generated flashcards, and quizzes.
4. *Student Copilot:* Personalized AI assistant aware of all hubs and deadlines.
